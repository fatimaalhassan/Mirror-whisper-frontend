# Mirror Whisper (Frontend)

Mirror Whisper is a motivational web application that provides users with positive and uplifting messages through an interactive mirror experience.

## 🪞 Description

Mirror Whisper is designed to encourage users through a calm and magical experience.  
After signing in or signing up, users are greeted by a Victorian-style mirror that invites them to interact. By clicking on the apple beneath the mirror, users receive a positive motivational message intended to uplift their mood and start their day on a positive note.

The project focuses on emotional well-being, clean UI design, and smooth user interaction.

## 🧑‍💻 User Stories

### 🔐 Authentication (Sign In / Sign Up)

- As a new user, I want to sign up using a username and password so that I can create an account and access the website.
- As a registered user, I want to sign in using my username and password so that I can access the mirror experience.
- As a user, I want to see an error message when I leave required fields empty so that I know what needs to be fixed.

### 🪞 Mirror Interaction

- As a user, I want to see a Victorian-style mirror on the second page so that the experience feels magical and immersive.
- As a user, I want to read the phrase  
  “Mirror, mirror on the wall, tell me something nice for today”  
  so that I understand what the mirror is meant to do.
- As a user, I want to click on the apple under the mirror so that I can trigger the next step of the experience.

### ✨ Motivation Page

- As a user, I want to see a positive and motivational message in English so that I feel encouraged and uplifted.
- As a user, I want the message to appear clearly in the center of the page so that it is easy to read and impactful.

### 🎨 Theme & Experience

- As a user, I want the website to use a navy blue and red color theme so that the design feels elegant and consistent.
- As a user, I want smooth transitions between pages so that the experience feels calm and magical.
